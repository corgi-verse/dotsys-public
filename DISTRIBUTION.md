# Public source distribution

This is a reviewed source-only distribution of the legacy DotSys 0.1.0 protocol and buildless site from source revision `1a96e99a696878a099f6a9b78d48985ec6860ae8`. It uses one new root commit; no upstream Git history, branches or pull requests are imported. The source revision identifies reviewed protocol/site provenance, not a private architecture proposal.

Included scope: portable protocol, strict schemas, synthetic examples and empty opt-in directory; setup/naming/handshake/documentation/security/verification guidance; offline reference tools and tests; original buildless landing and approved artwork; the existing bounded Paste Inbox source package; separately licensed CorgiPanels interoperability contract, structural validator and synthetic example. None supplies a hosted backend, connected account, working agent transport or execution grant.

Excluded scope: later polished three-site presentation and fixtures, private architecture drafts and design pins, private issue/PR references, upstream history, real System manifests/user captures, proposed community rule catalog and proposed panel-transport planning document, deployment workflows and website sitemap. The example named dotsys.json is explicitly synthetic, not a real private System.

Modifications are limited to distribution boundaries: public source/navigation links; truthful source-only website status; removal of private product-location and prototype-specific implementation/qualification notes and excluded-document links; matching test expectation for the new source URL; rebuilding the Paste Inbox ZIP from its reviewed retained source files. The protocol schemas, validators, protocol identifiers, three identical setup-prompt copies and applicable license/notices are retained. The CorgiPanels schema's original $id remains an identifier for the unchanged contract; it is not a private issue link or a hosting configuration.

SOURCE-MANIFEST.json enumerates every exported payload file with SHA256 and original source Git blob provenance, and identifies modified files. It does not include its own digest. No private machine paths, runtime configuration, credentials or private architecture source pins belong in the manifest.

Owner-supplied artwork retains the provenance and rights limitations in THIRD_PARTY_NOTICES.md; no new licensing claim is made.
