# A room for listening

A quiet, tactile direction for one person and one record. Owner-directed launch example by Hayden Lindley / Corgi-Verse, executed with OpenAI Codex and the built-in image tool. These are concept hypotheses, not photographs of a built room.

- [Original direction sheet](original/sheet.html), [editable brief](original/brief.json), [hash manifest](original/manifest.json).
- [Clay chair adaptation](clay/sheet.html), [editable brief](clay/brief.json), [hash manifest and verified parent](clay/manifest.json).
- [Actual generation/edit process and prompts](PROCESS.md), [run receipt](RUN.json).
- Producing tool: [Visual Concept Kit 1.0.0](../../tools/visual-concept-kit/README.md).

GitHub displays HTML source. Download/clone the folder and open sheet.html in a browser, or use the DotSys website's creation viewer. Keep all files together. The clay chair adaptation credits this original and changes only the named upholstery choice; it does not inherit an owner approval.

## Make a version

Use the producing tool's step-by-step workflow. Start by running `kit.py reopen` on the parent. Edit the selected image with the actual supported host image editor, change only chair_upholstery in the brief, and create a new output folder. Inspect the image, reopen the saved sheet, then submit the artifact, process and parent credit through CONTRIBUTING.md. No new account/provider is needed to view or copy this saved example.

Covered source and original brief follow repository LICENSE/NOTICE. Image rights/provenance and limitations are in PROCESS.md. Preserve original credit, process and license with adaptations.
