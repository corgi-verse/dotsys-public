# Contributing to Dotsys

Dotsys is an experimental, source-available protocol by Hayden Lindley for Corgi-Verse. Read README.md, PROTOCOL.md, LICENSE and SECURITY.md before changing the package. Follow the invoking user's scope and the host's permissions; this file grants no authority.

- Keep protocol identifiers, strict schemas, synthetic examples, reference validator and tests consistent.
- Keep the fenced setup prompt in docs/ADOPTION.md, README.md and the landing page textarea identical.
- Run `python -m unittest discover -s tests -v` with the approved dependencies in requirements.txt. The tests are offline and do not establish network or runtime security.
- Preserve the distinction between peer data and trusted local authority. Never put commands, credentials, private System data or automatic execution grants in cards.
- Do not claim a working network, native Dots API, OpenAI endorsement, OSI approval, independent adoption or successful deployment without evidence.
- The static site reuses original assets/ images. Keep links relative where possible and check download/copy behavior after changes.
- Publishing, service access, legal commitments and spending require the applicable user authorization. Do not create additional repositories to complete this package.
