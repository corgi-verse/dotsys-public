# Dotsys assets

Original SVG diagrams created for Dotsys, shared by the project README and static landing page. Site styling and clipboard behavior are dependency-free. These files are covered by the repository LICENSE.

`dotsys-brand.png` is owner-supplied branding included unchanged. See the repository THIRD_PARTY_NOTICES.md for provenance and rights limitations.

## Brand palette

Shared visual tokens: warm cream `#fffaf0`, ink `#23232f`, orange `#fb862d`, and accessible deep teal `#317366`. The diagrams echo the owner-supplied artwork with rounded forms, clear boundaries, and restrained accent color. Orange is paired with ink text; teal is darkened for readable text and focus indicators on cream.

`hero.svg` illustrates the permission boundary. `architecture.svg` uses a numbered two-column flow so it can scale in the README and landing page without a wide, horizontally scrolling strip. Both contain SVG titles and descriptions.
